# Module 1 — Foundations of Cybersecurity

## Overview

This module introduced me to the fundamentals of cybersecurity and the role of cybersecurity professionals in protecting organizations, systems, networks, and data.

## What I Learned

### 🔐 What is Cybersecurity?

Cybersecurity is the practice of protecting systems, networks, applications, devices, and data from unauthorized access, attacks, damage, or disruption.

Cybersecurity is important because organizations depend on digital systems and handle large amounts of sensitive information.

### 🎯 CIA Triad

The CIA triad is a fundamental concept in cybersecurity:

- **Confidentiality** — Ensuring information is accessible only to authorized people.
- **Integrity** — Ensuring information remains accurate and is not improperly modified.
- **Availability** — Ensuring systems and information are available when authorized users need them.

### ⚠️ Common Cybersecurity Threats

Some common threats include:

- Phishing
- Malware
- Social engineering
- Password attacks
- Denial-of-service attacks
- Unauthorized access

### 👩‍💻 Role of a Security Analyst

A security analyst helps protect an organization's systems and data by:

- Monitoring systems and networks
- Identifying potential security threats
- Investigating suspicious activity
- Responding to security incidents
- Helping prevent future attacks
- Following security policies and procedures

### 🏢 Importance of Security

Cybersecurity is not only a technical issue. Security professionals also need to understand an organization's risks, policies, procedures, and responsibilities.

## Key Takeaways

- Cybersecurity protects systems, networks, and information from threats.
- The CIA triad is a fundamental cybersecurity concept.
- Security analysts monitor, investigate, and respond to potential threats.
- Human behavior and organizational processes are important parts of cybersecurity.
- Good security requires both technical knowledge and responsible decision-making.

# Module 3 — Connect and Protect: Networks and Network Security

## Overview

This module introduced me to computer networks, how devices communicate, and how networks can be protected from security threats.

## 🌐 What I Learned

### Network Fundamentals

- A network allows devices to communicate and share resources.
- Devices communicate using protocols and defined rules.
- IP addresses are used to identify devices on a network.
- Network protocols help determine how data is transmitted between devices.

### 📡 Network Protocols

Some important protocols I learned about include:

- **TCP** — Provides reliable communication between devices.
- **UDP** — Allows faster communication without the same reliability mechanisms as TCP.
- **HTTP/HTTPS** — Used for communication between web browsers and web servers.
- **DNS** — Translates domain names into IP addresses.
- **SSH** — Allows secure remote access to systems.

### 🔢 IP Addresses

IP addresses identify devices on a network.

I learned about:

- IPv4
- IPv6
- Public and private IP addresses
- IP address allocation

### 🚪 Ports

Ports help identify specific services or applications running on a device.

Examples:

- **HTTP — 80**
- **HTTPS — 443**
- **SSH — 22**
- **DNS — 53**

### 🛡️ Network Security

Networks need to be protected against unauthorized access and attacks.

Some security measures include:

- Firewalls
- Network segmentation
- Secure protocols
- Encryption
- Authentication
- Monitoring network activity

### ⚠️ Network Threats

Some threats that can affect networks include:

- Denial-of-service (DoS) attacks
- Distributed denial-of-service (DDoS) attacks
- Network interception
- Spoofing
- Packet sniffing
- Man-in-the-middle attacks

## 💡 Key Takeaways

- Networks allow devices and systems to communicate.
- Protocols define how devices communicate.
- IP addresses identify devices, while ports identify services.
- Secure protocols and encryption help protect network communication.
- Network monitoring and security controls help detect and prevent attacks.

# Module 4 — Tools of the Trade: Linux and SQL

## Overview

This module introduced me to Linux and SQL and how these tools can be used by cybersecurity professionals to work with systems, files, and data.

## 🐧 Linux

### What I Learned

- Linux is an operating system commonly used in cybersecurity and IT.
- The command-line interface allows users to interact with a system using commands.
- Linux uses a file system to organize files and directories.
- File and directory permissions help control who can access or modify resources.

### Linux Commands

Some commands I learned include:

- `pwd` — Shows the current working directory
- `ls` — Lists files and directories
- `cd` — Changes the current directory
- `cat` — Displays the contents of a file
- `grep` — Searches for specific text
- `chmod` — Changes file permissions
